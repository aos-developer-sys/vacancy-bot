# Инструкции для Claude в этом репозитории

## Git

После внесения изменений в код этого репозитория (hh_bot.py, vacancy_bot.py,
config.py, filters.py, README и т.п.) — **спросить пользователя**, нужно ли
закоммитить и запушить эти изменения в `origin/master`. Не делать это
самостоятельно без подтверждения.

Если пользователь подтверждает — сделать оба шага:
1. `git status`/`git diff` — убедиться, что в диффе нет секретов (значений
   client_id/client_secret/токенов/паролей — только имена переменных).
   `.env`, `*.session`, `hh_token_cache.json`, `*.sqlite3`, `*.log` уже в
   `.gitignore` — не добавлять их силой (`git add -f`).
2. `git add -A`, коммит с описательным сообщением на русском (императивное
   наклонение в заголовке, при необходимости — буллеты с деталями ниже),
   затем `git push origin master`.

Если пользователь отказывается — оставить изменения в рабочей директории
незакоммиченными, не настаивать повторно в рамках той же задачи.

Ветка одна (`master`), отдельные feature-ветки для этого проекта не используются.
